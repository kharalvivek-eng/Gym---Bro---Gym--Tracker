# 💪 GYM BRO - Gym Tracker

GYM BRO is a simple terminal-based gym tracking application built with Python.

## Features

- Save user information
- View user information
- Track gym progress
- Record workout notes
- View saved gym progress and notes
- Store data using CSV files

## Technologies Used

- Python
- CSV module
- OS module

## Concepts Practised

- Variables and data types
- Lists and dictionaries
- While loops and conditions
- Functions of the CSV module
- File handling
- Exception handling (`try-except`)
- Input validation

## How to Run

1. Install Python.
2. Download or clone this repository.
3. Open the project folder in your terminal.
4. Run:

   `python gym_bro.py`
